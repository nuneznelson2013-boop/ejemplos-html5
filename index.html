¿Qué es CSS?

Definición

CSS son las siglas de Cascading Style Sheets. Se usa para dar color, tamaño, posición y diseño a los elementos HTML.

¿Para qué sirve?

Separar el diseño del contenido.

Reutilizar estilos en varias páginas.

Adaptar la web a móviles y tablets.

¿Por qué aprenderlo?

Sin CSS las páginas web se ven aburridas y sin estructura. Es la base del diseño web moderno junto con HTML y JavaScript.
